# 🗂️ Gestor de Tareas - Universidad Católica Luis Amigó

Aplicación de escritorio desarrollada en Java que permite gestionar tareas con una interfaz moderna e intuitiva.

---

## 🚀 Cómo usar la aplicación

1. Descargar y descomprimir el archivo:

```
app.zip/
```
2. Ejecutar el programa:
```
Doble clic al archivo TaskManager.jar o click derecho > abrir
```
2.1 Ejecutar el programa desde consola en caso de que el anterior pase no funcione:

```
java -jar TaskManager.jar
```

---

## 📋 Requisitos

* Java JDK 17 o superior
* Recomendado: JDK 21

Verificar instalación:

```
java -version
```

---

## ⚙️ Instalación de Java

Revisar la carpeta:

```
instalacion/
```

O descargar desde:

https://www.oracle.com/java/technologies/javase-downloads.html

---

## 📁 Estructura importante

```
app/
 ├── TaskManager.jar
 │──── usuarios.txt
 │──── tareas.txt
```

⚠️ No eliminar los archivos `usuarios.txt` y `tareas.txt` , es necesaria para el funcionamiento.

---

## ✨ Características

* Gestión de tareas (crear, editar, eliminar)
* Interfaz gráfica en Java Swing
* Persistencia de datos con archivos `.txt`
* Diseño adaptado a identidad institucional
